## What Was Fixed

### 1. Role-based resume matching (FR-026, FR-029–034)

`web/lib/role-detection.ts` now exports `detectRoleType()` with three deterministic regex patterns:

- **TPM:** Technical Program Manager, TPM, Staff TPM, Senior TPM, Principal TPM, Engineering Program Manager, EPM, IT Program Manager, Infrastructure Program Manager, etc.
- **Scrum Master:** Scrum Master, Agile Coach, Release Train Engineer, RTE, Agile Delivery Lead, Kanban Coach, etc.
- **PM:** Project Manager, Delivery Manager, Engagement Manager, PMO Lead, Portfolio Manager, Implementation Manager, etc.

The edge function (`supabase/functions/process-job/index.ts`) now selects the resume by `role_type` column first, falls back to `is_default`, then falls back to any resume.

### 2. ATS retry loop (FR-048–050)

The edge function now runs up to 3 tailor+score cycles. It stops early if ATS score ≥ 80. The best result across all attempts is saved. `ats_attempts`, `provider`, and `model` are now stored in `job_ai_results`.

### 3. PDF download (FR-060)

`web/lib/pdf.ts` implements `downloadResumeAsPdf()` using jsPDF with heading-level rendering and safe filename sanitization. The Download PDF button appears in ApplyActions when a tailored resume is available.

### 4. Apply button (FR-061)

An Apply button in ApplyActions downloads the tailored PDF and opens the job source URL in a new tab simultaneously.

### 5. Resume role_type UI (FR-024, FR-025, FR-027)

ResumeManager now shows a Role Type dropdown (TPM / PM / Scrum Master) when creating or editing a resume. One-per-role_type limit is enforced in both the UI (client-side check) and the API route (409 on conflict). The Add Resume button is hidden once 3 resumes exist.

### 6. Database schema gaps (DB-002–004)

Migration `supabase/005_audit_gap_fixes.sql` adds:
- `resumes.role_type TEXT CHECK ('tpm','pm','scrum_master')` with backfill
- `job_ai_results.ats_attempts INTEGER NOT NULL DEFAULT 1`
- `job_ai_results.provider TEXT`
- `job_ai_results.model TEXT`
- `user_settings.created_at TIMESTAMPTZ`
- Revokes INSERT/UPDATE/DELETE on `jobs` from `anon`
- Grants INSERT on `api_usage` to `authenticated` + adds RLS policy

### 7. Lint fixes

Both `ApplyActions.tsx` and `ResumeManager.tsx` converted async `load()` calls to synchronous functions using `.then()` chains, eliminating `react-hooks/set-state-in-effect` lint errors.
