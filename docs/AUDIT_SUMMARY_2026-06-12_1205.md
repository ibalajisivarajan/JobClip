## What Is Already Working

### Job capture and dashboard

The core capture and dashboard foundation is mostly working. Saved jobs appear in the dashboard. The Add Job page supports URL, copied job description, and URL plus description.

### Authentication

The app has authenticated dashboard access and shows the logged-in user in the top navigation.

### Profile page

The profile page exists and can store at least one master resume.

### Settings page

The settings page exists and supports AI processing toggle, provider selection, and model selection.

### Usage page

The usage page exists and is prepared to show API calls, token usage, cost, success rate, and request history once AI calls are recorded.

### Saved jobs page

The saved jobs page lists saved roles with company, role title, location, remote status, platform, ATS column, and saved date.

## Main Missing Items

### 1. Role-based resume matching is missing

Requirement:

```text
TPM job → TPM resume
Project Manager job → PM resume
Scrum Master job → Scrum Master resume
```

Current issue:

```text
The app mainly uses a default resume.
No proper TPM / PM / Scrum Master resume mapping yet.
```

Impact: AI may tailor the wrong resume for the job.

---

### 2. ATS retry loop is missing

Requirement:

```text
Tailor resume → score ATS → if below 80, retry up to 3 times → save best version
```

Current issue:

```text
The AI pipeline runs once.
No 3-attempt retry loop.
No threshold-based improvement cycle.
```

Impact: The resume may stay below the target ATS score.

---

### 3. PDF download is missing

Requirement:

```text
User should be able to download the tailored resume as PDF.
```

Current issue:

```text
No PDF download flow is implemented yet.
```

Impact: The app cannot yet produce the final resume file needed to apply.

---

### 4. Apply button is missing

Requirement:

```text
Apply button should open the job source URL and download the tailored PDF.
```

Current issue:

```text
Source URL is only a normal link.
No proper Apply button flow.
```

Impact: The application workflow is not complete.

---

### 5. Database schema still has gaps

Missing or incomplete items include:

```text
resumes.role_type
job_ai_results.ats_attempts
job_ai_results.provider
job_ai_results.model
user_settings.created_at
```

Impact: AI settings, role matching, audit tracking, and usage reporting are not fully complete.

## UI Status

### Good

- Profile page is straightforward.
- Settings page is clear.

### Needs improvement

- Jobs page needs search/filter.
- Jobs page needs Apply button.
- Job detail needs PDF download.
- Profile needs resume type selection.
- ATS status needs more useful detail.
- Many LinkedIn jobs show company as `Unknown`, so extraction quality needs improvement.

## Final Simple Verdict

**JobClip is at MVP+ foundation stage.**

The capture system is mostly ready.

The AI application-prep system is only about halfway ready.

Before calling it complete, fix these four things:

```text
1. Role-based resume matching
2. ATS retry loop
3. PDF resume download
4. Apply button
```

Once those are done, the score should move from about **67 / 100** to around **82–88 / 100**.
